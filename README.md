## 🧮 SQL scripts

В проект добавлен пример SQL-скрипта для аналитики данных.

### `sql/daily_revenue.sql`

Скрипт рассчитывает дневную выручку:

- группирует заказы по дате;
- считает количество уникальных заказов;
- считает общую сумму выручки;
- показывает только завершённые заказы.

Этот файл имитирует простую задачу junior data engineer / data analyst.
